# DANI — Waitlist

The official waitlist for **DANI** — Digital Artificial Neural Intelligence.
Built by Daminicodesphere.

She codes. She chats. She imagines. She talks.

## Flow
1. Landing — meet DANI, her abilities, tap **Join the Waitlist**
2. Her voice plays (voice note greeting) → email form
3. Email saved to the database → loading screen
4. Success → one-time chat with DANI (voice only)

## Stack
- Static site (deploy on Vercel → `dani.daminicodesphere.org`)
- Emails stored via Base44 backend: `daniWaitlist` function + `WaitlistEntry` entity

## Voice
Her voice note lives at `assets/voice/dani-intro.wav` (placeholder in place
until the real WAV is dropped in).
